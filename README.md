# 分析圖製圖台 · Diagram Drafting Table

貼上數值，選一種建築分析圖、風格與配色，產出帶圖框的靜態向量圖。單一 HTML 檔，無框架、無建置步驟、無後端。

## 兩個出口

| 出口 | 網址 | 限制 |
|---|---|---|
| claude.ai Artifact | 見下方 | 沙箱擋掉所有外部圖片與網路請求 |
| GitHub Pages | `index.html` | 無限制，可載圖磚與外部資料 |

兩邊跑同一份原始碼 `src/diagram-table.html`。Artifact 版直接發佈那個檔；Pages 版由 `py tools/build.py` 包上 doctype 後產生 `index.html`。

## 圖種

| id | 名稱 | 資料格式 |
|---|---|---|
| `share` | 面積配比 | `標籤, 數值` |
| `stack` | 樓層堆疊 | `樓層, 值, 值…` |
| `column` | 高度對照 | `標籤, 值…` |
| `radar` | 條件雷達 | `項目, 方案A, 方案B` |
| `rose` | 方位玫瑰 | `方位, 值` |
| `bubble` | 機能泡泡 | `機能, 面積` |
| `matrix` | 時段熱力 | `空間, 時段值…` |
| `site` | 基地疊圖 | `圖層, 名稱, 型, 座標, 值` |
| `section` | 垂直動線 | `樓層\|機能, 進深, 樓梯, 電梯` |
| `users` | 使用者分析 | `族群, 佔比, 年齡下, 年齡上, 起, 迄` |

一般圖種每行一筆、逗號或 Tab 分隔，第一行以 `#` 開頭時當欄位名。欄名寫成 `中文|ENGLISH` 會出雙語標題。

### 基地疊圖的圖層語彙

格式跟其他圖種不同，一行一個圖面物件：

```
圖層, 名稱, 型, 座標, 值
```

`型` 有六種：

| 型 | 畫成什麼 | 座標欄放什麼 |
|---|---|---|
| `基地` | 測量十字標 + 虛線基地範圍 | 一點或多點多邊形 |
| `點` | 圓，面積 ∝ 值 | 一點 |
| `流` | 平滑路徑 + 箭頭，線寬 ∝ 值 | 多點路徑 |
| `區` | 填色多邊形 | 多點多邊形 |
| `風` | 三道彎曲風箭頭 | 方位角 0–360 |
| `光` | 日照弧線 + 太陽 + 光線方向 | 方位角 0–360 |

座標寫 `x y`（底圖百分比），多點用 `;` 分隔。同一個「圖層」的物件在分析板模式會收成同一格。

## 版面

- **單張圖**：一張圖佔滿圖紙
- **分析板**：2×2 / 3×2 / 3×3 / 4×2 / 1×3 小倍數，一格一個圖層，方框加編號徽章或圓框置中標題

## 圖幅與輸出

A4 / A3 / A2 / 正方 / 16:9，橫直皆可；96 / 150 / 300 / 600 dpi。

- **複製 SVG 向量碼** — 貼進 Illustrator 或 Figma 就是可編輯向量，字體完整
- **複製 PNG** — 依所選 dpi 算圖。⚠️ SVG 轉點陣時載不到 webfont，字會換成系統替代字
- **列印／存成 PDF** — `@page` 會依所選圖幅設定

## 本機開發

```bash
py tools/build.py && py -m http.server 8778 --bind 127.0.0.1
```

然後開 http://localhost:8778/

## 測試

```bash
node tests/smoke.js
```

Stub DOM 跑完 10 種圖 × 2 種版面 × 27 種選項組合，檢查空輸出、`NaN`、`undefined`、巢狀 `<svg>` 不對稱，另外做差分測試確認配色與版面切換真的改變輸出。

## 已知限制

- Artifact 版載不到地圖圖磚（CSP），只能上傳自己的底圖
- PNG 輸出的字體會 fallback
- 分析板一格一圖層，同一塊板上不能混不同圖種
