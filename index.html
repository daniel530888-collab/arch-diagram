02 數值 Data

每行一筆：標籤, 數值, 數值…　逗號或 Tab 分隔。
第一行以 # 開頭時當作欄位名。
基地疊圖格式不同：圖層, 名稱, 型, 座標, 值。
型＝基地 點 流 區 風 光。座標寫 x y（底圖百分比）， 多點用 ; 串成路徑或多邊形；風和光那一欄改填方位角 0–360。 在圖面點一下可直接新增一個點。

02b 地圖底圖 Base Map

依「底圖實際寬度」自動選縮放級別，抓完會把寬度改寫成實測值。

或在頁面任意處按 Ctrl+V 貼上地圖截圖。
底圖只留在這台裝置的瀏覽器裡，不會上傳。

03 版面 Layout

分析板一格一個圖層：基地疊圖依「圖層」欄分格，其餘圖種依數值欄分格。 欄名寫成 中文|ENGLISH 就會出雙語標題。
